# NeoPen integration boundary

This reserved module will map a supported, licensed NeoLAB SDK into `docs/data-contract.md`. It must preserve immutable raw input and capture provenance before recognition or NLP.

The vendor-neutral event boundary is [Stroke Event v0.1](schema/stroke-event.schema.json). It carries full Ncode page identity, ordered input state, pressure, and time without bundling a vendor SDK.

Do not add vendor SDKs, Ncode patterns, certificates, page ranges, or customer captures.
