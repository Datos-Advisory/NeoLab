# Daily Templates

Initial templates:

- Daily Time Log: date, time zone, start/end time, activity, notes, total.
- Daily Task List: date, task, status, priority, notes, review.

An Ncode edition is separate and requires vendor-approved page allocation, authoring, print validation, and device testing.

For immediately usable official Ncode paper, see the [NeoLab Ncode-paper catalog](../docs/ncode-papers.md). These downloads are not NeoLab templates and remain hosted by NeoLAB.
