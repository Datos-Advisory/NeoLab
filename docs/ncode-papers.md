## Print and test procedure

1. Download the required file from NeoLAB above.
2. Print through Adobe PDF Reader on a color laser printer using its PCL/PS driver at its highest-quality/actual-size setting.
3. Test a small number of pages with the intended smartpen before a full print run.
4. If using a grayscale laser printer, use NeoLAB's Plain layout recommendation.
5. In Neo Studio2, enable or disable smartpen input for the relevant page ranges when reusing a printable, as described by NeoLAB.

The printer driver and testing recommendations are NeoLAB guidance, not a recognition guarantee. Record printer model, driver, paper, scaling setting, pen model, app version, and test outcome for each print run.
